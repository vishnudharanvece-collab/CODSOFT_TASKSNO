# CodSoft Blockchain Development Internship

## Overview
This repository contains three smart contract projects developed using Solidity and Hardhat 3.

## Tasks Completed

### Task 1: Simple Storage
- Store and retrieve integer values.
- Increment and decrement values.
- Prevent decrementing below zero.
- Automated tests included.

### Task 2: Student Certificate Verification
- Issue certificates with unique IDs.
- Verify certificate authenticity.
- Retrieve student and course details.
- Prevent duplicate certificate IDs.
- Automated tests included.

### Task 3: To-Do List
- Add tasks.
- Update task completion status.
- Retrieve task details.
- Store task creation timestamps.
- Automated tests included.

## Technologies Used
- Solidity
- Hardhat 3
- TypeScript
- Node.js
- Viem
- Git and GitHub

## Installation

```bash
npm install
```

## Compile Contracts

```bash
npx hardhat compile
```

## Run Automated Tests

```bash
npx hardhat test
```
